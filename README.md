# REPO Save Guard

Утилита для Windows, которая сохраняет резервные копии забегов R.E.P.O. и автоматически возвращает пропавшие сейвы. После успешного прохождения уровня копия обновляется, как только игра завершит запись автосейва.

## Запуск

1. Соберите `RepoSaveGuard.exe` по инструкции ниже и запустите его перед игрой. В кооперативе утилиту запускает хост.
2. Дождитесь статуса «Защищён» у своего сейва. Кнопка «Свернуть в трей» оставляет защиту включённой.
3. Если после смерти сейв исчез, подождите около пяти секунд, затем загрузите его из главного меню игры.

Папка сейвов по умолчанию — `%USERPROFILE%\AppData\LocalLow\semiwork\Repo\saves`. Кнопка «Папка копий» открывает историю в `%LOCALAPPDATA%\REPO Save Guard\Backups`. Утилита хранит до 30 последних версий каждого сейва и восстанавливает отсутствующий файл забега. Уровни в таблице отображаются так же, как в меню R.E.P.O.

Утилита определяет потерю по исчезновению файла, поэтому восстанавливает и вручную удалённые сейвы. Чтобы убрать забег навсегда, закройте утилиту, удалите забег в игре и удалите соответствующую папку из истории копий. Затем запустите утилиту снова.


Рядом со скриптом появится `RepoSaveGuard.exe` со встроенной иконкой. Для запуска не нужны BepInEx, Python или права администратора.

Чтение сохранений проверено на R.E.P.O. v0.5.2. Автотесты проверяют обновление копии, восстановление исчезнувшего файла, защиту от повреждённых записей и хранение истории.
